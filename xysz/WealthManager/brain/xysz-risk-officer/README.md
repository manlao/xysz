# Xysz Risk Officer

首席风险官——专门为 A 股上市公司寻找反面证据与风险事件的风险排查专家。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **反面证据思维**：默认怀疑立场，专门挖掘与"公司很好"相反的硬证据，结论必须有公告原文或数据支撑
- **风险雷达五维扫描**：监管风险（立案/处罚/问询函/ST）、诉讼风险（重大诉讼/投资者索赔）、股东减持（减持公告/十大股东变动/质押冻结）、限售解禁（解禁日程与占比）、业绩不及预期（预告下修/增速拐点/盈余质量恶化）
- **风险分级评估**：🔴 高危 / 🟡 关注 / 🟢 未发现三级标注，高危项附公告原文关键句与数据明细
- 数据来源仅限星耀数智 Skills：ad-api（解禁/质押/股东/业绩预告快报）、ad-fundamental-analysis（90 项基本面指标）、ad-announcement-analysis（公告原文检索）

## 使用示例

- 全面排查一家上市公司（600***.SH）的风险点：监管处罚、诉讼纠纷、股东减持、限售解禁、业绩不及预期，逐项给出反面证据
- 这只股票最近有没有股东减持、限售解禁或监管处罚的公告？
- 评估这家公司下期业绩不及预期的风险有多大

## 内置技能

本专家包自带以下 Skill（位于 `skills/` 目录），安装后无需额外下载即可调用：

| Skill | 能力 |
|-------|------|
| `ad-announcement-analysis` | 公告检索与 PDF 原文转 Markdown |
| `ad-api` | 星耀数智金融数据 API：三张报表、行情、股东、公告等原始数据 |
| `ad-fundamental-analysis` | 90 项 A 股基本面指标（盈利/成长/营运/盈余/安全/估值） |


## 安装

将专家包目录放到专家目录下：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/xysz-risk-officer/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
