# Buddy 应用配置说明 — 中国银河证券（v3：4 模式 × 21 场景胶囊）

基线为你更新后的平台导出包（`wb-app-ref/cb_new/`），保留了你已配置的 header 标题、onboarding、jointAuth、模型池等全部内容，只把每个模式的 `scenes: []` 填上了场景胶囊。

## 场景胶囊清单（21 个，每模式 ≥5）

| 模式 | 胶囊（→绑定专家） |
| --- | --- |
| mode_0 财富规划（5） | 家庭风险测评→稳舵；大类资产配置→稳舵；ETF定投测算→长流；定投计划书→长流；自选股关注池→稳舵 |
| mode_1 深度分析（5） | 财务分析→财探；技术分析→盘眼；风险排查→风探；市场观点→风哨；个股全景体检→财探（四维组长） |
| mode_2 量化策略（6） | 单因子分析/多因子合成/多因子筛选→宽客；形态捕手/条件筛选/多指标策略回测→试金 |
| mode_3 模拟交易（5） | 模拟买入/模拟卖出/查模拟账户/撤单管理/绩效复盘→弈者 |

每个胶囊含：中英名称、绑定专家、绑定技能（用户不可见）、系统提示词（用户不可见，含合规话术）、4 条提示词模板（标题中文≤8字+英文≤30，指令中英双份）。完整指令文本见 `industry-config.json` 或录入对照表 `scene-capsules.md`。

## 文件

| 文件 | 说明 |
| --- | --- |
| `industry-config.json` | 主配置：模式+场景胶囊+i18n+模型+授权（基于你的新导出，scenes 已填） |
| `market.json` | 与你的新导出一致（连接器 unit 条目；专家/技能在平台侧选择，不在 JSON 里） |
| `scene-capsules.md` | 场景胶囊平台表单录入对照表（21 个，含图标配色建议） |

## 校验结论（脚本已过）

- 21 个胶囊 id 唯一；每模式 5/5/6/5；绑定专家全部在 9 个已上架专家内
- 每胶囊模板 4 条（4-10 区间内）；模板标题中文字数全部 ≤8
- market.json 与平台新导出逐字一致

## ⚠️ 推断项（导入后人工核对）

场景胶囊的真实 JSON schema 平台未导出（`scenes: []` 为空），`industry-config.json` 里 scenes 的字段名（`id`/`name`/`expertId`/`skills`/`systemPrompt`/`promptTemplates`）是按你截图的表单字段推断的。**若导入后胶囊为空**：打开 `scene-capsules.md`，在平台「场景胶囊设置」表单里按表逐个录入，21 个胶囊的全部文本都在表里（模板指令、系统提示词可直接复制）。

## 录入建议

1. 先导入 `industry-config.json` 试一次，预览看胶囊是否出现
2. 没出现就按 `scene-capsules.md` 手工录入（约 21 次表单操作，每次 1 专家 + 1~3 技能 + 1 提示词 + 4 模板）
3. 图标可后补：建议按模式配色（财富=金、深度=蓝、量化=紫、交易=红），SVG ≥48×48
