# Xysz Market Intel Officer

风哨——从上市公司公告、新闻舆情与券商研报三路情报中捕捉市场风向的市场情报官。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **风向研判三层框架**：事实层（公告硬事实）→ 传播层（舆情热度与主题）→ 定价层（机构评级与目标价），三层互证后才下风向结论（偏暖/中性/偏冷/分歧）
- **预期差识别**：找出"公告事实 vs 舆情情绪 vs 机构观点"的裂口，双向呈现可能超预期与可能低于预期的信号
- **非结构化信息解码**：公告事件分级、舆情主题聚类与热度追踪、研报评级/目标价变动统计，文字流翻译为结构化信号
- **关键事件链与催化剂**：按时间排"公告—报道—研报"因果链，指出下一可验证观察时点（解禁日、业绩窗口、监管节点等）
- 数据来源仅限星耀数智 Skills：ad-announcement-analysis（公告）、ad-smart-news（新闻舆情）、ad-report-abstract（研报摘要）

## 使用示例

- 观察一只股票（600***.SH）近一个月的市场风向：汇总公告、新闻舆情与研报观点，判断市场情绪偏暖还是偏冷，预期差在哪里
- 对比同行业两只股票（600***.SH 与 000***.SZ）近一个月的舆情热度与机构评级变化，看市场更青睐谁
- 梳理一只股票（600***.SH）近一个月的重大公告与研报目标价调整，找出市场预期差与下一个催化剂

## 内置技能

本专家包自带以下 Skill（位于 `skills/` 目录），安装后无需额外下载即可调用：

| Skill | 能力 |
|-------|------|
| `ad-announcement-analysis` | 公告检索与 PDF 原文转 Markdown |
| `ad-report-abstract` | 研报摘要与机构观点统计 |
| `ad-smart-news` | 新闻多源去重归并与舆情主题分类 |


## 安装

将专家包目录放到 WorkBuddy 的专家插件目录（plugins/marketplaces/my-experts/plugins/）下，保持目录名不变：

```
xysz-market-intel-officer/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
