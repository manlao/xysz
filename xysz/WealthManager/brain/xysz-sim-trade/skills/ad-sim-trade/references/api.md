# 接口与错误码

12 个柜台接口，全部返回 `(res, error_code)` 二元组，**不抛异常**。

## 返回值约定

| 项 | 说明 |
|---|---|
| `res` 类型 | 列表类接口返回 `DataFrame`；单对象类返回 `dict`；`insert_order` 返回 `order_id` 字符串 |
| `error_code` 类型 | **字符串**。成功 `'00000'`；入参未校验 `None`；失败为具体错误码（**可能带负号**） |
| 空值 | `res` 中所有空值统一为 `None`，**不会是 `NaN` / `<NA>`** |
| 判成功 | **必须 `code == '00000'`**，不可用真值判断 |

`error_code` 为 `None` 表示**入参未通过校验、请求未发出**，常见原因：证券代码格式非法、查询类 `code` 未传 list、日期格式非 8 位整数、`side` 超出 Buy/Sell、组合名称为空。

同一错误码在不同接口下含义可能不同，不跨接口套用。

## 交易类接口（7 个）

### insert_order — 下单

```python
order_id, error_code = trade.insert_order(
    account_id, '600***.SH', 9.70, 100,
    trade.SideType.Buy, trade.PriceType.Limit)
```

| 参数 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `account_id` | str | 是 | 资金账户id（组合编号） |
| `code` | str | 是 | 代码+市场，**下单是单个字符串，不受 list 规则影响** |
| `limit_price` | float | 是 | 委托价格 |
| `volume` | int | 是 | 委托数量 |
| `side` | SideType | 是 | 仅 `Buy` / `Sell` |
| `price_type` | PriceType | 是 | 按市场校验；**本技能恒用 `Limit`** |
| `buss_id` | int | 否 | 业务类型，默认 0；非 0 为比赛 id（不暴露） |

返回 `order_id`（str），可直接回传 `cancel_order`。

### cancel_order — 撤单

```python
res, error_code = trade.cancel_order(order_id, account_id)
```

`order_id` 取自委托查询的 `counter_order_id` 列，int/str 均可。返回 `order_status`（见枚举）。

### query_asset — 查资金

返回 dict：`account_id` / `total_asset` / `market_value` / `leaves_value` / `init_leaves_value` / `available_t1` / `frozen_all`

### query_position — 查持仓

| 参数 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `account_id` | str | 是 | 资金账户id |
| `code` | list[str] | 否 | **必须传 list，单只也写 `['600***.SH']`；最多 1 只** |

固定 12 列，见 [fields.md](fields.md)。

### query_order — 查委托

| 参数 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `account_id` | str | 是 | 资金账户id |
| `code` | list[str] | 否 | **必须传 list** |
| `order_status` | list[str] | 否 | **必须传 list**，如 `['Filled']` |
| `begin_date` / `end_date` | int | 否 | 8 位整数，**必须成对使用**；**不传即查当日** |
| `action_in` | int | 否 | 0 查委托（默认）；1 查可撤单委托（此时只返回可撤单委托，不与区间委托合并） |

**日期区间规则**：

- `begin_date` 与 `end_date` **成对使用**（要么都传、要么都不传）；
- 传日期区间时，只要**区间结束日不早于当日**，返回结果**一定包含当日委托**——当日尚未完成盘后清算也能查到，无需等待。

### query_trade — 查成交

参数同上（无 `order_status`）。**不传日期即查当日。**

### query_max_qty — 查最大可买/卖

| 参数 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `account_id` | str | 是 | 资金账户id |
| `code` | str | 是 | **单个字符串** |
| `side` | SideType | 是 | `Buy` / `Sell` |
| `limit_price` | float | 是 | 委托价格 |

返回 dict：`available`（可用资金）/ `max_qty`（最大可买卖数量）

## 组合类接口（4 个）

入参统一用 `account_id`（取自 `get_portfolio_list` 的 `account_id` 列），**不是组合名称**。

> ⚠️ **每个用户最多只能建 1 个组合**（后台限制），已建则无法再建。

### create_portfolio — 新建组合

| 参数 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `portfolio_name` | str | 是 | 1~50 字符，同用户下唯一 |
| `begin_fund` | float | 否 | 初始资金 >0，默认 1000000.00。**本技能固定 100 万，不开放为参数** |
| `description` | str | 否 | 0~200 字符 |
| `acct_type` | int | 否 | 当前仅支持 `0`（普通账户） |
| `stc_id` | int | 否 | 0-普通，>0-比赛/活动 |

单次只能建**一个**组合。**每个用户总共只能建 1 个**——建过之后无法再新建。

### get_portfolio_list — 查组合列表

| 参数 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `status` | int | 否 | 0-删除 / 1-正常（默认）/ 2-开户中 / 3-开户失败 |

四个取值都是合法入参；某账户下没有对应状态的组合时返回**空行，不是错误**。

固定 9 列，见 [fields.md](fields.md)。

### get_portfolio_benefits_info — 组合收益数据

| 参数 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `date` | int | 否 | 8 位整数，空表示不限 |
| `account_ids` | list[int] | 是 | **资金账户id列表**，支持一次查多个 |

固定 25 列，见 [fields.md](fields.md)。

### get_portfolio_benefits_rate — 历史收益率曲线

| 参数 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `account_id` | int | 是 | 资金账户id |
| `begin_date` / `end_date` | int | 否 | 8 位整数，空表示不限 |
| `len` | int | 否 | 记录条数（与日期区间二选一），默认 10000 |

固定 2 列：`date` / `profit_rate`

## 枚举取值

均从 `trade` 模块直接导入。

### MarketType 市场类型

| 枚举值 | 说明 | 代码后缀 |
|---|---|---|
| All | 全市场 | — |
| SSE | 上交所 | .SH |
| SZSE | 深交所 | .SZ |
| BSE | 北交所 | .BJ |

### SideType 委托方向

**仅两个**：`Buy` 买入 / `Sell` 卖出

### PriceType 委托类型

| 枚举值 | 说明 | 上交所 | 深交所 | 北交所 |
|---|---|---|---|---|
| Limit | 限价，证券通用 | 可用 | 可用 | 可用 |
| Best5OrLimit | 最优五档即时成交剩余转限价，需要报价 | 可用 | — | — |
| ForwardBest | 本方最优价格申报 | 可用 | 可用 | — |
| ReverseBest | 对手方最优价格申报 | 可用 | 可用 | — |
| Fak | 即时成交剩余撤销 | — | 可用 | — |
| Fok | 全额成交或者撤销 | — | 可用 | — |
| FakBest5 | 最优五档即时成交剩余撤销 | — | — | — |

> 本技能**仅支持限价（`Limit`）**，其余类型不对用户开放。

### OrderStatusType 委托状态

| 枚举值 | 说明 | 终态 |
|---|---|---|
| New | 已申报，订单被交易所确认 | |
| PartiallyFilled | 部分成交 | |
| Filled | 全部成交 | ✔ |
| PartiallyFilledPartiallyCancelled | 部分成交、部分撤销 | ✔ |
| Cancelled | 已撤销 | ✔ |
| PartiallyCancelled | 部分撤销 | |
| Reject | 已拒绝 | ✔ |
| WaitCancelled | 待撤销，撤单尚未成功 | |
| PartiallyFilledWaitCancelled | 部成待撤 | |

### Exchange 交易所

`BJ` 北交所(2) / `SH` 上交所(101) / `SZ` 深交所(102)

### Variety 交易品种

`all` 全部(0) / `stock` 股票(1) / `fund` 基金(2) / `bond` 债券(3) / `cvtbond` 可转债(20)
