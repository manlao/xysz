# 弈者 · 模拟交易大赛参赛专家

中国银河证券星耀数智模拟交易专家的**比赛专用版本**。为「银河星耀数智 × 腾讯 WorkBuddy 模拟交易大赛」参赛者提供从建仓、下单、监控到赛后复盘的全流程支持。

## 类型

Agent 型（单个 AI 专家）

## 功能

**参赛建仓**：先用提问确认参赛组合名称（给带策略标识与年季度的默认名选项），再以固定描述「模拟比赛参赛」建立组合，随后给出参赛账户全景（总资产、持仓市值、可用资金、持仓明细、在途委托）。**每个用户只能建 1 个组合且不支持删除**，所以建仓前必须先查已有组合——已有就直接复用，不重复新建。

**盘中执行**：把自然语言意图翻译成合规的限价委托。金额类指令（"买 10 万"）先按现价折算成符合交易单位的股数并报出取整损耗，再走自动取价与行情时间戳标注；下单前做交易单位、最小价位、限价上下限、资金与持仓充足性校验；大额与清仓单需参赛者点头后才确认。

**在途跟踪**：跟踪委托、成交与持仓，严格区分 `available_qty`（可用）与 `leaves_qty`（总持股），识别 T+1 锁定、卖出冻结与废单占位行。

**赛后复盘**：输出组合收益、净值曲线、最大回撤、胜率与盈亏比，并接入绩效分析给出夏普、卡玛、Beta、Alpha 等相对基准指标。

## 使用示例

- 我要参加模拟交易大赛，帮我建一个参赛组合并拉出当前账户情况
- 帮我用参赛账户买 600***.SH，投入 10 万左右
- 帮我把参赛账户里的 600***.SH 卖一半，先告诉我现在能卖多少、费用多少

## 依赖

本专家调用已安装的星耀数智技能，不含独立数据实现：

| 技能 | 用途 |
|------|------|
| `ad-sim-trade` | 组合建立（限 1 个、不可删）、限价委托下单撤单、持仓/委托/成交/资金查询、组合收益与净值曲线、可视化报告 |
| `ad-strategy-performance` | 赛后绩效评估与 HTML 报告 |
| `ad-api` | 盘中与复盘时的行情、基础信息查询 |

需配置环境变量 `AD_USERNAME` / `AD_PASSWORD` / `AD_HOST` / `AD_PORT` 后方可连接柜台。

## 头像

头像在 `avatars/` 目录下。如需替换为自定义头像，要求：
- 格式：PNG（推荐）或 JPG
- 尺寸：512×512 px
- 大小：单张不超过 500KB

## 内置技能

本专家包自带以下 Skill（位于 `skills/` 目录），安装后无需额外下载即可调用：

| Skill | 能力 |
|-------|------|
| `ad-api` | 星耀数智金融数据 API：三张报表、行情、股东、公告等原始数据 |
| `ad-sim-trade` | 模拟交易柜台（下单/撤单/持仓/委托/成交） |
| `ad-strategy-performance` | 策略净值业绩评估（收益/风险/基准/调整后收益） |


## 安装

将专家包目录放到专家目录下（`$WORKBUDDY_CONFIG_DIR/plugins/marketplaces/my-experts/plugins/`，未设置时默认 `~/.workbuddy/plugins/marketplaces/my-experts/plugins/`），然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
