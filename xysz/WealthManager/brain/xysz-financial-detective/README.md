# 财探 · 星耀数智财务分析专家（xysz-financial-detective）

运用财务分析框架（财探八看）解读 A 股三张报表：看战略、看资产管理与竞争力、看效益与质量、看成本决定机制、看项目质量、看风险、看价值、看前景。数据全部来自星耀数智 Skills，不使用任何外部行情/财经数据源。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **星耀数智财务分析框架"财探八看"**：战略 → 资产管理与竞争力 → 效益与质量 → 成本决定机制 → 项目质量 → 风险 → 价值 → 前景，逐层落到具体科目与数字
- **三张报表战略解读**：经营/投资资产结构、经营性/金融性负债、核心利润、母公司报表 vs 合并报表的因果与扩张效应
- **"三质量"识别**：资产质量、利润质量、现金流量质量；高现金存量、并购商誉、造血/输血结构等风险信号
- **关键指标**：核心利润、核心利润率、经营资产报酬率、核心利润获现率、总资产周转率等

### 数据来源（铁律）

| 数据需求 | 使用的 Skill |
|---------|-------------|
| 三张报表原始数据（母公司+合并、多期） | `ad-api` |
| 90 项财务指标核验与补充 | `ad-fundamental-analysis` |
| 财报/业绩预告/重大事项公告原文 | `ad-announcement-analysis` |

## 使用示例

- 用星耀数智财务分析框架分析一家集团型公司（600***.SH）母公司报表与合并报表的差异，看其战略选择与资产结构
- 拆解一家成长型公司（300***.SZ）的核心利润与核心利润获现率，判断利润含金量
- 对比一家公司（000***.SZ）的负债结构：经营性负债占比与造血能力如何？

## 内置技能

本专家包自带以下 Skill（位于 `skills/` 目录），安装后无需额外下载即可调用：

| Skill | 能力 |
|-------|------|
| `ad-announcement-analysis` | 公告检索与 PDF 原文转 Markdown |
| `ad-api` | 星耀数智金融数据 API：三张报表、行情、股东、公告等原始数据 |
| `ad-fundamental-analysis` | 90 项 A 股基本面指标（盈利/成长/营运/盈余/安全/估值） |


## 安装

将专家包目录放到专家目录下（相对 WorkBuddy 配置目录 `~/.workbuddy/`）：

```
plugins/my-experts/plugins/xysz-financial-detective/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r xysz-financial-detective.zip xysz-financial-detective/
```
