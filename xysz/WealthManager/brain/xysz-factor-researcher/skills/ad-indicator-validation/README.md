# 风险提示

1. **历史回测结果不代表未来表现。** 回测净值基于历史数据统计,市场结构、交易制度、参与者行为都可能变化,历史有效的策略未来可能失效。

2. **过拟合风险。** 反复调整指标组合、参数与阈值以匹配历史净值,属于样本内寻优,极易产生过拟合。建议在样本外区间验证,并对参数敏感性做稳健性检查。

3. **未来函数是回测失真的首要来源。** 本 skill 已在收益对齐(当日信号次日计收益)、复权、股票池(含退市股)等环节做防护,但使用者自行扩展指标或接入新数据源时,务必确保所用信息在信号生成时点之前已知。扩展方法见 backtest_methodology.md 第 6 节。

4. **成本与撮合为近似模型。** 佣金/印花税/过户费/滑点按现行标准费率与收盘价撮合近似,未建模冲击成本、零股约束与一字板盘口。小资金、高换手方案的实际成本可能显著高于回测值,请务必对照含成本与不含成本两条净值。

5. **涨跌停与停牌处理为近似。** 用昨日涨跌停近似今日无法成交,ST 判定基于当前证券简称,无法回溯历史戴帽期。

6. **数据依赖。** 回测质量受底层数据(行情、复权因子、退市信息)完整性与准确性影响,服务端数据修订可能导致结果变化。

7. **本工具输出为历史统计结果,仅供研究参考,不构成任何投资建议。** 用户应自行判断并承担投资风险。
