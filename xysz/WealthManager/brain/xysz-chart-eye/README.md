# 盘眼 ChartEye（xysz-chart-eye）

A股技术分析专家：通过技术分析识别关键支撑位、压力位与趋势状态。

## 类型

Agent 型（单个 AI 专家）

## 功能

以「盘眼看盘五步」框架解读个股技术面：

1. **辨势** —— 多周期均线系统（MA/EXPMA/BBI）+ 趋势指标（MACD/DMI），先分清趋势市与震荡市
2. **察标** —— 趋势型、超买超卖型、量能型三类指标跨类别共振验证，单一指标不下结论
3. **察背** —— 价格与 MACD/KDJ/RSI 的顶背离、底背离识别，背离是势能衰减信号而非反转信号
4. **观量** —— 量价关系验证：放量突破、缩量回踩、天量天价，结合 OBV 判断筹码流向
5. **定位** —— BOLL/ENE/MIKE/CDP + 前期高低点给出关键支撑区与压力区，只陈述位置含义

配套心法：指标是价格的影子、量才是心跳；金叉死叉人人会看，背离和位置才是功力；单一指标必失效，多类共振才有意义。

## 依赖技能

专家通过名称引用以下两个星耀数智技能（需在使用前已安装）：

| 数据需求 | 技能 |
|---------|------|
| 日K/周K等历史行情数据 | `ad-api` |
| 56项技术指标计算（7大类） | `ad-technical-analysis` |

## 使用示例

- 用盘眼框架分析一家上市公司（600**.SH）的技术面：先辨趋势级别，再看MACD/KDJ/RSI是否共振，最后给出支撑压力位
- 上市公司（***）当前价格与MACD、KDJ有没有顶背离或底背离？
- 从量价关系看，上市公司（***）近期这波上涨是放量健康还是缩量虚涨？

## 目录结构

```
xysz-chart-eye/
├── .codebuddy-plugin/
│   └── plugin.json          # 专家清单（展示信息、技能引用）
├── agents/
│   └── xysz-chart-eye.md    # 专家人设与方法论（盘眼五步框架）
├── avatars/
│   └── expert.png           # 头像
└── README.md
```

## 头像

头像位于 `avatars/expert.png`（512×512，PNG）。如需替换为自定义头像，要求：
- 格式：PNG（推荐）或 JPG
- 尺寸：512×512 px
- 大小：单张不超过 500KB

## 内置技能

本专家包自带以下 Skill（位于 `skills/` 目录），安装后无需额外下载即可调用：

| Skill | 能力 |
|-------|------|
| `ad-api` | 星耀数智金融数据 API：三张报表、行情、股东、公告等原始数据 |
| `ad-technical-analysis` | 56 项 A 股技术面指标计算 |


## 安装

将本目录放入 WorkBuddy 专家目录 `plugins/marketplaces/my-experts/plugins/` 下，然后运行注册命令使其可见：

```bash
python scripts/register_expert.py xysz-chart-eye
```
