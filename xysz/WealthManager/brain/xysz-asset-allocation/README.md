# 稳舵 · 家庭资产配置专家

以家庭资产负债表为起点的资产配置专家：先问清家庭收入、负债、子女教育、父母赡养等情况，算出**亏得起多少**和**必须赚多少**，再匹配黄金 / 国债 / 宽基 / 窄基 / 现金五类资产，并用历史回测检验方案扛不扛得住。

## 类型

Agent 型（单个 AI 专家）｜分类：金融投资（`08-FinanceInvestment`）

## 功能

| 能力 | 说明 |
|------|------|
| 家庭财务问诊 | 结构化采集收入、支出、负债、家庭成员、流动性、期限、既有持仓、行为型风险偏好，输出家庭财务画像卡 |
| 风险承受力定档 | 用现金流口径量化：`可承受回撤金额 = 月可投资结余 × 投资期限 × 风险容忍系数` → 风险预算 → C1–C5 风险档 → 权益上限，附降档/升档规则 |
| 预期收益目标反推 | 从真实财务目标反解必须实现的年化（调用 `ad-etf-dca` 的 `target_return`），并与该档位历史合理区间比对判定可行性 |
| 大类资产匹配 | 黄金 / 国债 / 宽基 / 窄基 / 现金五类资产，调用 `ad-asset-allocation` 的固定权重、均值方差、风险平价、BL 四模型生成候选方案 |
| 定投路径落地 | 把目标权重翻译成每期定投金额与标的，测算 IRR 与达成目标所需年化 |
| 回测交付 | 净值对比、权重演变、绩效表（年化 / 波动 / 最大回撤 / 夏普 / 卡玛）与 fresh-light 风格可视化 HTML 报告 |

**核心原则**：风险档位与人的真实处境必须匹配。给高杠杆、有幼儿、要还贷的家庭上 60% 权益，不是激进，是错配。

## 使用示例

- 我月薪3万，有房贷和两个上学的孩子，10年不动这笔钱，帮我做一份资产配置方案并跑回测
- 我有50万闲钱，5年内要用掉一半，剩下的怎么配黄金、国债和宽基？给我回测报告
- 每月定投5000到沪深300和红利ETF，10年后能到多少钱？

## 自带脚本

| 脚本 | 用途 |
|------|------|
| `bin/calc_pi.py` | 打印 BL 模型的市场均衡先验 Π（`search.py --mode alloc` **不打印** Π，但采集主观观点必须有参照系）。默认口径实测：黄金 5.9% / 国债 0.0% / 宽基 3.5%，黄金相对宽基价差 2.4 个百分点 |
| `bin/rebalance_calc.py` | 从目标权重 + 当前持仓生成**可照着下单的调仓清单**：偏离分析、换手最小化的卖出顺序、100 份取整、最低佣金估算、资金缺口诊断、分期调仓建议。支持 `--sell-first` 只买不卖模式 |

## 核心算法（v2，已实测修订）

风险承受力的资本基础是**存量可投资资产**，不是未来结余 —— 未来还没投入的钱不存在回撤。

```
应急储备     = 月刚性支出 × 6
存量可投资产 = 流动资产合计 − 应急储备        （自住房/车不计入）
最大亏损额   = 存量可投资产 × 行为容忍回撤 D     （D 取 6% / 12% / 25% / 35%）
风险预算     = D ÷ 2                          （安全边际，实测回撤/波动比 1.3–1.8）
回本时间     = 最大亏损额 ÷ 月可投资结余         （≥24 个月则降 1 档）
目标折算     = 目标金额 × (1+通胀)^年数        （长期目标必做）
目标缺口     = 折算后目标 − 存量可投资产        （反推只用缺口，不含存量）
```

**算法自查清单**（纯算式，不含市场数字）在 Agent MD Step 2 末尾，逐项验算逻辑是否算错。

## 数据纪律：不写死任何市场数字

**方法论只写「怎么算」，不写死「算出来是多少」。** 市场数据随时间变化，把某一天的实测值写进方法论，会在几个月后变成误导性的"事实"。

| 数据 | 何时取 | 怎么取 |
|------|-------|--------|
| 四大类资产行情/波动/回撤 | **每次会话** | `ad-asset-allocation --mode backtest` |
| BL 均衡先验 Π | **每次采集 BL 观点前** | `bin/calc_pi.py`（`search.py --mode alloc` 不打印 Π） |
| 下单价格（手数取整） | **每次调仓** | `bin/rebalance_calc.py` 自动取星耀数智最新收盘价（不复权），**绝不用硬编码价格** |
| 目标所需年化 | **每个用户目标** | `ad-etf-dca --mode target_return` |

**绝不在方法论里硬编码**：ETF 价格、资产年化/回撤、Π 值、档位年化区间上界。这些必须运行时实跑。

已固化的**算法**（与市场无关，可放心依赖）：
- 风险预算 = 行为容忍回撤 D ÷ 2（÷2 是安全边际，依据"回撤/波动比"经验值，需按当期回测校准）
- 目标缺口 = 通胀折算后目标 − 存量可投资产（反推只对缺口，不含存量）
- 替代方案必须在**现实年化假设**下重算，不能用反解出的年化（否则同义反复）

**四条实测得出的铁律**（机制性结论，长期有效，已写入 Agent MD）：
1. 模型可能退化成"现金堆"（均值方差 60% 国债 40% 现金），须点破是数据环境的机械结果而非方案
2. BL 无观点时与固定权重数值完全相同，不要当两个方案展示
3. 绩效排序 ≠ 适合该客户，选模型依据是风险预算能否承受回撤
4. **不要用反解出的年化去反解替代方案**（同义反复，答案回到原点）；**反推只对"目标缺口"，不含存量本金**

## 安装

专家包目录（相对 WorkBuddy 配置目录 `~/.workbuddy/`）位于：

```
plugins/my-experts/plugins/xysz-asset-allocation/
```

注册命令（使其在专家中心可见）：

```bash
python3 scripts/register_expert.py <expert-dir>
```

⚠️ **注册 ≠ 装上**：`register_expert.py` 只更新 marketplace 注册项。还需确认 `installed_plugins.json` 有对应条目、且 `~/.workbuddy/plugins/cache/my-experts/xysz-asset-allocation/<version>/` 下有副本，WorkBuddy 才会真正加载。

## 打包分享

```bash
python3 scripts/package_expert.py <expert-dir>
```
