# 大类资产配置模型算法说明

> 与 `scripts/models.py` 一一对应；年化口径 244 个交易日；资产顺序 `['黄金', '国债', '宽基', '现金']`。
> 记号：μ 为年化预期收益向量（N×1），Σ 为年化协方差矩阵（N×N），w 为权重向量，λ 为风险厌恶系数。

---

## 0. 共性环节

### 0.1 估计量（annualized_stats）

```
μ  = mean(窗口日收益) × 244
Σ  = cov(窗口日收益) × 244
可选收缩（--shrink δ）：Σ' = (1−δ)·Σ + δ·diag(Σ)    # 对角收缩，治样本协方差病态
```

### 0.2 权重合法性（check_weights）

所有模型输出必须通过：`Σw = 1`（容差 1e-4）、`w ≥ 0`（多头）、逐资产落在上下界内。

### 0.3 回测合成（backtest.drifted_returns）

- 调仓日 t（每月/周/年第一个交易日）：**t 日开盘按目标权重调仓，t 日收益按新权重计算**；
- 调仓区间内权重随价格漂移：`w_d ← w_{d-1} ⊙ (1+r_d) / (1+r_p,d)`，其中 `r_p,d = w_{d-1}·r_d`；
- 窗口估计期（前 lookback 个交易日）净值平推 NAV=1，绩效只按有效投资期计算。

---

## 1. 固定权重（fixed_weight）

**输入**：用户指定权重列表（可选，默认等权 1/N）。

```
w = 用户权重 / sum(用户权重)        # 归一化，不做优化
```

特点：无估计量、无优化器，行为完全可预期；回测中充当其他模型的对照基线。

---

## 2. 均值方差（mean_variance，Markowitz 1952）

**优化问题**：

```
max_w   μᵀw − (λ/2)·wᵀΣw
s.t.    Σwᵢ = 1
        0 ≤ loᵢ ≤ wᵢ ≤ hiᵢ        # --bounds，默认单资产上限 60%
```

**求解**：scipy SLSQP，等式约束 Σw=1 + 边界，初值等权，ftol=1e-12，maxiter=500。
失败判定：`res.success=False 且 res.fun 非有限` → 抛错；数值清理（负值截 0、归一化）后输出。

**要点**：
- μ 的估计误差远大于 Σ，优化器会放大误差形成角点解（0%/100%），实践必须配边界；
- λ 越小越激进（λ→∞ 退化为最小方差组合）；
- 权重仍过度集中时开 `--shrink 0.2` 收缩 Σ。

---

## 3. 风险平价（risk_parity）

**风险贡献**（绝对口径，ΣRC = 组合波动 σ_p）：

```
RC_i(w) = w_i · (Σw)_i / σ_p,    σ_p = √(wᵀΣw)
```

**优化问题**（风险预算目标函数）：

```
min_w   J = Σᵢ ( RC_i(w) − σ_p/N )²      # 等风险贡献目标
s.t.    Σwᵢ = 1,  wᵢ ≥ 0（可加上下界）
```

**求解**：SLSQP，初值等权，ftol=1e-16，maxiter=1000。

**⚠️ 现金退化处理**：固定收益模拟的现金方差恒为 0，此时 100% 现金是 J=0 的平凡解。
实现中对 Σ 对角加 `1e-6` 方差地板（年化波动约 0.1%）后再求解；
即便如此现金权重仍会显著偏大，建议 `--bounds` 给现金设上限（如 40%）。

---

## 4. Black-Litterman（black_litterman，标准 He-Litterman 1999）

**第 1 步 隐含均衡收益**（先验）：

```
Π = δ · Σ · w_eq        # δ=λ 风险厌恶系数，w_eq 默认等权
```

**第 2 步 观点输入**（K 个观点，JSON 文件 `--views`）：

```
P（K×N）：第 k 行为观点 k 的资产系数
     绝对观点 {'p': {'宽基': 1.0}}               → q 读作该资产年化收益
     相对观点 {'p': {'黄金': 1.0, '宽基': -1.0}} → q 读作年化价差（百分点）
Q（K×1）：观点目标收益（年化，如 0.08）
conf（K）: 信心水平（0,1)，默认 0.5
```

> **纯相对观点自动归一化**：系数和为 0 的纯相对观点，程序按 `max|p| = 1` 自动缩放。
> 因为 P 是原样进公式的，不缩放时 q 的量纲会跟着系数走——写 `{'黄金':0.1,'宽基':-0.1}`
> 配 `q=0.03`，数学含义是"黄金跑赢宽基 **30** 个百分点"而非 3 个，会把组合推向单一资产满仓。
> 归一化后无论写0.1/-0.1 还是 1.0/-1.0，q 统一读作年化价差，结果一致。绝对观点不归一化。

**第 3 步 观点不确定性矩阵**（对角；标准置信度比例法）：

```
Ω = τ · (1−conf)/conf · diag( P·Σ·Pᵀ )
```

含义：**conf 就是"后验期望落在该观点上的权重"**（conf=0.6 ≈ 六成权重给观点），
conf→1 观点被完全采纳，conf→0 退回市场先验。该式与 Idzorek (2005) 刻度因子法
（τcf = conf/(1−conf)）完全等价；`--omega legacy` 可切到不含 τ 的历史口径
`Ω = diag(PΣPᵀ)/conf`（该式把观点影响严重压低，仅用于复现旧结果）。

**第 4 步 后验期望与后验协方差**（τ 默认 0.05，`--tau`）：

```
A     = (τΣ)⁻¹ + PᵀΩ⁻¹P
E[R]  = A⁻¹ · [ (τΣ)⁻¹·Π + PᵀΩ⁻¹Q ]      # 后验预期收益
M     = A⁻¹
Σ_bl  = Σ + M                              # 后验协方差（He-Litterman）
```

**第 5 步 MVO 落地**：在 (E[R], Σ_bl) 上解与均值方差相同的优化问题。

**退化行为**：无观点时 E[R]=Π、Σ_bl=Σ → 严格退化为均衡组合（等权先验下即等权），符合理论。

**⚠️ 数值保护**：现金方差为 0 使 τΣ 奇异，求逆前对 Σ 对角加 1e-6 地板；
所有矩阵求逆走稳健封装（近奇异或求逆失败自动改用**伪逆 pinv** 并打印告警）。

## 5. 业界常见变体与参数标定

以下为公开文献与业界通行做法，用于理解本 skill 默认口径的取舍；不含任何具体机构或研报来源。

### 5.1 观点误差矩阵 Ω 的几种构造

| 构造 | 公式 | 本 skill |
|---|---|---|
| 置信度比例法（默认 `--omega ratio`） | `Ω = τ(1−conf)/conf · diag(PΣPᵀ)` | ✅ 实现；conf 即后验观点权重 |
| 刻度因子法（`--omega idzorek`） | 同上，τcf = conf/(1−conf) | ✅ 实现（与 ratio 同一公式） |
| 独立法 | `Ω = diag(σ_i²)`，σ 取观点资产历史波动 | 未实现（忽略观点相关性，最简单） |
| 时变法（GARCH 等） | Ω 随市场状态变化 | 未实现（需额外模型） |
| 历史口径（`--omega legacy`） | `Ω = diag(PΣPᵀ)/conf`（不含 τ） | ✅ 实现，仅用于复现旧结果 |

> ⚠️ 历史口径（不含 τ）把观点影响系统性压低：τ=0.05 时 conf=0.5 仅约 2.4% 权重给观点、
> conf=0.9 也只有约 50%，与"conf 表示信心"的直觉严重不符。新计算请用默认 ratio 口径。

### 5.2 数值稳健性：伪逆（pinv）

协方差矩阵接近奇异时直接求逆常给出**极端权重**。业界通行做法：用伪逆替代 Σ⁻¹、
缩短协方差估计窗口、或对角收缩。**本 skill 已全部落地**：`_inv_spd()` 对 τΣ、Ω、A
统一做条件数判断，>1e10 或求逆失败/出现非有限值时自动改用伪逆并告警；
另有 Σ 对角 1e-6 地板 + `--shrink` 对角收缩 + 求解未收敛告警。

### 5.3 用超额收益估计 Σ

用资产相对基准的**超额收益 alpha** 估计协方差，可避免"高市场风险资产反而获得高权重"
与参数不稳定的问题。**本 skill 已实现**：`--excess-cov` 以沪深300（000300.SH）为基准，
μ 仍取原始收益均值，Σ 的**风险资产部分**改用超额收益协方差；现金是低风险代理资产，
若也用超额收益其波动将等于基准波动、低风险属性被破坏，故**现金对角与现金-风险资产
相关项保留原始收益口径**（混合口径，仅用于稳健性对照）。基准行情按需现取，
取不到时自动退回原始收益协方差并告警。

### 5.4 τ 与 δ（λ）的标定

- **conf 才是决定后验的主杠杆**：标准口径下 Ω 与 (τΣ)⁻¹ 同阶缩放，后验期望 E[R] 对 τ
  近似不敏感（τ 只影响后验协方差的膨胀项 M=τA⁻¹）；公开实证常用 conf∈[0.3, 0.9]。
- λ（风险厌恶）常用区间 [0, 7]；本 skill 默认 λ=2、τ=0.05。
- **工具**：`scripts/param_scan.py` 做 conf×λ（默认）或 τ×λ（`--scan tau --omega legacy`）
  网格扫描，输出绩效 + "权重平均变动%"（跨期稳定性代理）+ 最新权重，CSV 带时间戳落盘。
  选参顺序：先看稳定性（权重变动小、可解释），再看夏普；单点最优不可复现时取邻近 plateau 中心值。

### 5.5 观点标定的经验规律

- 观点的**相对大小关系**比绝对水平更重要：Q 整体等比例放大/缩小对结果影响有限。
- 观点数不宜过多；K 接近资产数时，观点实际上在"重新拟合先验"，失去 BL 的稳健性意义。
- 信心水平越低 / τ 越大 → 权重越靠近均衡先验；不做观点时 BL 严格退化为均衡组合。

### 5.6 观点的自动化来源（进阶方向，本 skill 未实现）

- 投资时钟 / 美林时钟：宏观周期 → 资产表现排序 → 生成 Q；
- 资产价格的周期分解（如频域周期因子）→ 生成 Q；
- 因子回归或分析师一致预期（如一致预期 ROE）→ 生成 Q。

本 skill 目前只接受人工给定的观点 JSON（`--views`），不自动生成观点。

## 6. 数据口径依赖（详见 model_notes.md）

- 前复权：取 AD 累计后复权因子归一化 `F(d)=bf(d)/bf(最新日)`，`adj(d)=raw(d)×F(d)`；
- 宽基合成：5 只 ETF 逐日可得成分等权平均；
- 现金：固定年化模拟（实操对应 511880）或 511360 短融ETF 实测。
