# 模型口径说明

## 0. 运行环境

- 实测组合：Python 3.13.9 + AmazingData 1.1.15 + numpy 2.5.3 / pandas 2.3.3 / scipy 1.16.3。
- 凭证走环境变量 `AD_USERNAME` / `AD_PASSWORD` / `AD_HOST` / `AD_PORT`。
  ⚠️ `AD_PORT` 必须是 **int**（底层 uint16），从环境变量读出后需 `int()` 转换；
  传字符串报 `TypeError: Cfg_server_port_set`。
- ⚠️ **直接运行脚本（不走 MCP）时环境变量缺失会导致进程崩溃或挂死**：
  - 缺 `SystemDrive` → tgw 原生库拼接内部路径失败，访问违规退出（0xC0000005）；
  - numba 缓存目录解析为异常路径时，`import AmazingData` 会卡死在 `os.open`。
  - 完整可用组合：`SystemDrive=C: SystemRoot=C:/Windows TEMP=<本地临时目录> TMP=<同上>
    NUMBA_CACHE_DIR=<本地临时目录>/numba_cache PYTHONIOENCODING=utf-8`。
  - 用 `python -u` 运行，避免输出缓冲导致的假死误判。
- 数据源实测可达：`BaseData().get_calendar()` 返回约8700+ 个交易日即视为连通正常。
  偶发接口返回 None 致 `'NoneType' object is not subscriptable`，通常隔日自愈，遇此类
  报错可提示稍后重试。

## 1. 数据层

- **前复权构建**：取星耀数智 `get_backward_factor` 的**累计后复权因子** bf(d)（自上市起累积，
  全历史无缺失、起点 1.0，已含分红与拆分/合并影响），按区间内最新日归一化：
  `ff(d) = bf(d) / bf(区间末日)`，`adj(d) = raw(d) × ff(d)`（末日 ff=1，锚定真实收盘价）。
  事件日 bf 与原始价格反向跳变、相乘后相互抵消，序列连续，无需手工累乘。
  不使用 `get_adj_factor`（单次复权因子，仅事件日有值，直接相乘会在事件次日反向假跳变）。
- **已处理事件**：512100.SH 2022-09-05 份额合并（raw 0.982→2.713）；510300.SH 每年分红。
- **现金口径**：511880 货币ETF 价格序列不含收益（收益靠份额结转），直接用其价格
  收益年化仅 ~0.2% 且失真。方案：固定年化 1.8% 模拟（默认）或 511360 短融ETF 实测
  （年化 ~2%、日波动 0.046%、最大回撤 -1.06%，2022 年底债市赎回潮）。511990 华宝添益
  同 511880 问题，排除。

## 2. 模型

- **均值方差**：max μᵀw − (λ/2)wᵀΣw；μ = 窗口日均×244，Σ = 窗口日协方差×244；
  SLSQP，Σw=1、多头、上下界（默认单资产上限 60%，`--bounds none` 关闭）。
- **风险平价**：J = Σ(RC_i − σ_p/N)² 最小化（等风险贡献目标）。现金方差加 1e-6 地板（年化波动 0.1%）防止退化
  （零方差资产使 J 在 100% 现金处取得平凡解 0）。
- **BL（标准 He-Litterman）**：
  - 先验 Π = δ·Σ·w_eq（w_eq 等权，δ = λ）
  - Ω = diag(PΣPᵀ)/conf（conf 越高 Ω 越小）
  - E[R] = [(τΣ)⁻¹ + PᵀΩ⁻¹P]⁻¹ [(τΣ)⁻¹Π + PᵀΩ⁻¹Q]
  - Σ_bl = Σ + M，M = [(τΣ)⁻¹ + PᵀΩ⁻¹P]⁻¹
  - MVO 落地于 (E[R], Σ_bl)
  - 无观点时 E[R]=Π、Σ_bl=Σ → 退化为均衡组合（等权先验下即等权），符合理论。

## 3. 回测

- 调仓频率 y/m/w（每期第一个交易日）；调仓日开盘重设权重、区间内权重随价格漂移。
- 窗口：调仓日前 lookback=244 个交易日估计 μ/Σ；数据起点自动前伸窗口长度。
- 宽基合成：5 只宽基 ETF 逐日**可得成分**等权平均（563300 上市前自动用前 4 只）。
  该口径为**每日等权再平衡**，与组合的月度/季度调仓节奏不同；563300 于 2023-09 上市后
  成分由 4 只变 5 只，宽基收益序列在该时点存在**结构性断点**（历史期不含中证A500，
  风格上更接近沪深300+中证500），跨断点比较需注意。
- NAV0=1；基准：等权组合（同期再平衡口径）+ 各单资产买入持有。
- 绩效：年化按**有效投资期**计算（锚点=窗口末日 NAV=1，窗口估计期不计入年限），244 交易日/年；
  夏普 =(年化 − rf)/年化波动，rf 默认 0 而组合已含现金仓位收益，故偏乐观，跨工具比较需对齐口径。
- BL 观点：一条观点在整段回测的全部调仓期**恒定使用**，不逐期更新或衰减，
  等价于假设观点在整个样本期内持续有效；观点语义通常是"未来一年"，用于更长样本时需自行判断合理性。
- 输出：文件名带参数指纹与时间戳，多次运行不覆盖；nav CSV 与 HTML 净值曲线只含有效投资期
  （已裁掉窗口估计期的平推段），下游可直接用于绩效分析。
- 已知简化：无交易成本/冲击成本、按收盘价成交。
