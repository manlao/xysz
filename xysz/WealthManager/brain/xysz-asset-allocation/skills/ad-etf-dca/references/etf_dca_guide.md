# ETF 定投策略说明

## 定投原理

定投（Dollar Cost Averaging, DCA）是在固定时间、投入固定金额买入同一标的的投资策略。核心优势：
- **摊平成本**：价格低时买更多份额，价格高时买更少
- **降低择时风险**：不需要判断市场高低点
- **纪律性**：克服人性追涨杀跌

## 定价与收益计算

### 前复权价格（红利再投资）

本计算器使用**前复权收盘价**，天然内含红利再投资效应：

- 前复权以当前价格为基准，倒推历史价格
- 分红除息时，复权因子把除息缺口修补回去
- 使用前复权价计算收益 = 红利再投资全收益口径

### IRR vs 简单收益率

定投不能简单用 `(期末资产 - 总本金) / 总本金` 来衡量，因为资金是分批投入的，存在时间价值差异。

#### IRR（内部收益率）

适用于等间隔定投（按月、按周等），求解使净现值为零的贴现率 r：

$$
\sum_{i=0}^{n} \frac{C_i}{(1+r)^i} = 0
$$

其中 $C_0, C_1, \dots, C_{n-1}$ 为每期投入（负值），$C_n$ 为期末资产（正值）。解出的 r 为**每期收益率**，年化后：

$$
\text{IRR}_{\text{年化}} = (1+r)^k - 1
$$

其中 k 为每年定投期数。使用 **scipy.optimize.newton** 牛顿迭代法数值求解。

#### XIRR（扩展内部收益率）

适用于不等间隔定投（回测模式中日期间距不完全相等），求解满足下式的 r：

$$
\sum_{i=0}^{n} \frac{C_i}{(1+r)^{(d_i - d_0)/365.25}} = 0
$$

其中 $d_i$ 为第 i 笔现金流对应的日期。解出的 r 直接为**年化收益率**。同样使用牛顿迭代法，不收敛时降级为二分法。

## 前复权价格计算

本计算器通过两步合成前复权价格：

1. **原始K线** (`MarketData.query_kline`) → 获取不复权的收盘价
2. **后复权因子** (`BaseData.get_backward_factor`) → 获取后复权因子
3. **合成公式**：
   ```
   前复权收盘价 = 原始收盘价 × (当日复权因子 / 最新复权因子)
   ```

## 数据字段速查

### K 线数据 (MarketData.query_kline)

| 字段 | 说明 |
|------|------|
| open | 开盘价（不复权） |
| high | 最高价（不复权） |
| low | 最低价（不复权） |
| close | 收盘价（不复权） |
| volume | 成交量 |
| amount | 成交额 |

### 复权因子 (BaseData.get_backward_factor)

返回 `{code: DataFrame}`，index 为日期，值为后复权因子。用于合成前复权价。

公式：`前复权收盘价 = 原始收盘价 × (当日后复权因子 / 最新后复权因子)`

## 风险提示

- 计算结果基于历史数据或预期模拟，不构成投资建议
- 过往业绩不代表未来收益
- 市场有风险，投资需谨慎
- 前复权价格不等于实际交易价格，实盘以最新市价为准
