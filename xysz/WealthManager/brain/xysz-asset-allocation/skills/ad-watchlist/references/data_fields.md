# 数据字段定义

每只自选股在 HTML 展示与 `list` 命令中呈现以下字段。

## 基础信息

| 字段 | 含义 |
|------|------|
| `代码` code | 股票代码（如 `000001.SZ`） |
| `名称` name | 股票名称（自动补全） |
| `市场` market | 所属市场（SH/SZ/BJ） |
| `板块` list_plate | 上市板块（主板/创业板/科创板等） |
| `自选原因` watch_reason | 添加时备注，可留空（展示为 `-`），用 `-r/--reason` 指定 |

## 行情数据

| 字段 | 含义 | 计算方式 |
|------|------|----------|
| `自选价` watch_price | 添加时记录的价格 | 默认=添加时最新价，可用 `-p` 指定 |
| `自选时间` watch_time | 添加时间 | 替代原 added_at 语义 |
| `最新价` last_price | 最近交易日收盘价（前复权） | 取自日 K 线，剔除未收盘（0 值）Bar |
| `涨幅` change_pct | 较上一交易日涨跌幅 % | 前复权口径 |
| `涨跌` change_val | 较上一交易日涨跌额 | 前复权口径 |
| `成交额` amount | 最近交易日成交额（元） | — |
| `成交量` volume | 最近交易日成交量 | — |
| `本周涨幅` chg_week | 本周以来涨跌幅 % | 前复权口径 |
| `本月涨幅` chg_month | 本月以来涨跌幅 % | 前复权口径 |
| `今年涨幅` chg_year | 年初至今涨跌幅 % | 前复权口径 |

## 基本面数据

| 字段 | 含义 | 计算方式 |
|------|------|----------|
| `PB` pb | 市净率 | 总市值 / (归母净资产 - 其他权益工具) |
| `PE(TTM)` pe | 市盈率 TTM | 总市值 / 归母净利润 TTM |
| `总股本(亿)` tot_share | 总股本（亿股） | — |
| `总市值` tot_mktcap | 收盘价 × 总股本（元） | — |
| `流通股本(亿)` float_share | 流通 A 股股本（亿股） | — |
| `流通市值` float_mktcap | 收盘价 × 流通股本（元） | — |

## 衍生指标

| 字段 | 含义 | 计算方式 |
|------|------|----------|
| `自选收益` profit_pct | 自选以来涨跌幅 % | (最新价 - 自选价) / 自选价 × 100 |
