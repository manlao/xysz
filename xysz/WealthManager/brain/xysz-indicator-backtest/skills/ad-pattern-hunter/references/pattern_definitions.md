# 形态定义与算法手册（pattern_definitions）

本文档给出形态猎手内置 34 类形态的**算法**：公共预处理、每类形态的结构定义、逐步判定过程、规则权重表与模板轮廓。与 `scripts/pattern_engine.py` 一一对应；文中阈值为方法论常量，不随市场环境调整。

---

## 0. 公共预处理与评分（所有形态共用）

### 0.1 输入

前复权日线 OHLCV，取最近 $N$ 根（$N \in \{30, 60, 120\}$）。记收盘价序列 $c_1, \dots, c_N$，最高价 $h_i$、最低价 $l_i$、成交量 $v_i$（缺失时量能类规则自动跳过权重）。

### 0.2 z-score 归一化

$$z_i = \frac{c_i - \bar{c}}{\sigma_c}, \quad \bar{c} = \frac{1}{N}\sum_{i=1}^{N} c_i,\quad \sigma_c = \sqrt{\tfrac{1}{N}\sum (c_i - \bar c)^2}$$

$\sigma_c \to 0$（一字板等）时 $z \equiv 0$。所有形状类比较均在 $z$ 域进行，保证与价格尺度无关。

### 0.3 局部极值点（pivot）

平滑度参数 $k = \max\left(2, \lfloor N/12 \rfloor\right)$（$N{=}120 \Rightarrow k{=}10$）。

- **峰**：下标 $i$ 满足 $z_i \ge \max(z_{i-k},\dots,z_{i-1})$ 且 $z_i \ge \max(z_{i+1},\dots,z_{i+k})$，且至少一侧严格大于（允许平台但排除重复）。
- **谷**：镜像定义。
- **平台去重**：相邻同类极值间距 $< \lfloor k/2 \rfloor$ 时，保留更极端的那个（峰取 $z$ 更高者，谷取更低者）。

### 0.4 线性回归

对任意序列 $y_1,\dots,y_m$ 以 $x = 0,1,\dots,m-1$ 做最小二乘：

$$\text{slope} = \frac{\sum (x-\bar x)(y-\bar y)}{\sum (x-\bar x)^2}, \qquad R^2 = 1 - \frac{SS_{res}}{SS_{tot}}$$

$m = 2$ 时视为完全拟合（slope $= y_2 - y_1$，$R^2 = 1$）；$m < 2$ 返回 $(0, 0)$。

### 0.5 公共统计量

| 量 | 定义 |
|---|---|
| gain | $c_N / c_1 - 1$ |
| mdd | $\max_i \left(1 - c_i / \max_{j \le i} c_j\right)$（运行峰值口径） |
| pos_last | $(c_N - \min c) / (\max c - \min c)$ |
| MA快 / MA慢 | 简单均线，窗口 $\lfloor N/8 \rfloor$（$\ge 5$）与 $\lfloor N/3 \rfloor$（$\ge 10$） |

### 0.6 周期与幅度缩放（多周期支持）

引擎支持 13 个周期（`min1..min120 / day / week / month / season / year`）。阈值按**日线 120 BAR** 语义校准；同样 120 根在其他周期上时间跨度不同（周线 120 根 ≈ 2.3 年、60 分钟 120 根 ≈ 1.5 个月），波动尺度差异用**幅度缩放因子 amp** 校正：

| 周期 | min1 | min3 | min5 | min10 | min15 | min30 | min60 | min120 | day | week | month | season | year |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| amp | 0.12 | 0.18 | 0.25 | 0.32 | 0.40 | 0.50 | 0.62 | 0.78 | **1.0** | 1.6 | 2.2 | 3.0 | 4.0 |

- **参与缩放**：所有百分比类阈值——涨跌幅（gain/腿幅/旗杆）、回撤（mdd/lift/drop_back）、振幅（旗面/箱体/平台）、形态相对量（杯深/头深/肩差/颈线容差/确认幅度/平底偏差）等约 40 处，实现为 `阈值 × ctx.amp`；
- **不参与缩放**：z 域斜率与 R²（z 归一化后天然尺度无关）、相对比例（回撤/前段涨幅之比、σ 之比、收敛比）、区间位置（0.35N~0.85N）、根数与窗口比例、量能比、缺口容差；
- amp 为**经验常量**，可用阈值回检方法（按周期重扫命中率分布）校准；
- day 周期 amp=1.0，行为与单日线性完全一致。

### 0.7 评分与门槛

```
总分 = 规则命中分 × 60% + 形状相似分 × 40%
规则命中分 = (命中规则权重之和 / 规则权重之和) × 100
形状相似分 = max(0, Pearson corr(窗口 z 序列, 模板轮廓)) × 100
```

候选进入结果需同时满足：①规则命中分 ≥ 该形态规则门槛（默认 30）；②总分 ≥ 命中分数线（全局默认 50，宽结构形态设更高形态级门槛，见下表）。profile 模式下分数线约束**形状相似分**。

| 形态级门槛 | 形态 |
|---|---|
| 规则门槛 50 | W底、M头 |
| 总分门槛 60 | W底、M头、杯柄形、圆弧底、下降三角形、对称三角形、下降楔形 |
| 总分门槛 65 | 底部反转、顶部反转 |
| 总分门槛 70 | 阴跌通道 |

## 一、趋势延续类（8 类）

### 1. strong_trend 强趋势延续（看多）

**算法步骤：**
1. gain $\ge 15\%$；
2. 对 $z$ 做线性回归，$R^2 \ge 0.5$（走势线性度高）；
3. mdd $\le 12\%$；
4. 均线多头排列：$c_N > \text{MA快}_N > \text{MA慢}_N$（当 $N <$ 慢线窗口 + 2 时退化为 $c_N > \text{MA快}_N$）；
5. pos_last $\ge 0.8$。

| 规则 | 权重 |
|---|---|
| 线性斜率显著向上 | 3 |
| 走势线性度高 | 2 |
| 途中回撤可控 | 2 |
| 均线多头排列 | 2 |
| 收于窗口高位 | 1 |

### 2. trend_pullback 趋势回踩（看多）

**算法步骤：**
1. 取分界 $k = \lfloor 0.6N \rfloor$，前段涨幅 $\text{first\_gain} = c_k / c_1 - 1 \ge 10\%$；
2. 回撤 $d = 1 - c_N / \max(c_1..c_k)$，要求 $0.15 \times \text{first\_gain} \le d \le 0.60 \times \text{first\_gain}$；
3. 回踩不破起涨点：$c_N > c_1$；
4. 尾段企稳：$m = \max(5, \lfloor N/10 \rfloor)$，$\min(c_{N-m+1..N}) > \min(c_1..c_k)$；
5. gain $\ge 5\%$。

| 规则 | 权重 |
|---|---|
| 前段上涨显著 | 3 |
| 回撤适度 | 2 |
| 回踩不破起涨点 | 2 |
| 尾段企稳 | 2 |
| 整体仍上行 | 1 |

### 3. channel_up 上升通道（看多）/ 4. channel_down 阴跌通道（看空）

**算法步骤：**
1. 高点序列 $p^h = \{z_i : i \in \text{peaks}\}$，低点序列 $p^t = \{z_i : i \in \text{troughs}\}$，分别回归得 $(s_h, R_h)$、$(s_t, R_t)$；
2. 上升通道要求 $s_h > 0.02$ 且 $s_t > 0.02$；阴跌通道要求 $s_h < -0.02$ 且 $s_t < -0.02$（斜率单位：σ/极值步）；
3. 通道规整：$R_h \ge 0.6$ 且 $R_t \ge 0.6$；
4. 顺向净变动：$s \times \text{gain} \ge 15\%$；
5. 上升通道 mdd $\le 18\%$；阴跌通道 pos_last $\ge 0.1$（仍处窗口下沿区）。

| 规则 | 权重 |
|---|---|
| 极值点充足（各 ≥2） | 2 |
| 高点沿通道同向 | 2 |
| 低点沿通道同向 | 2 |
| 通道规整 | 2 |
| 顺向净变动 | 2 |
| 未反向破位 | 1 |

### 5. flag_up 上升旗形（看多）/ 6. flag_down 下降旗形（看空）

**算法步骤：**
1. 分界 $k = \lfloor 0.4N \rfloor$；旗杆幅度 $\text{pole} = s \times (c_k / c_1 - 1) \ge 12\%$；
2. 旗面 body $= c_{k+1..N}$，振幅 $(\max - \min)/\bar{c}_{body} \le 9\%$；
3. 对 $s \times (c - \bar{c}_{body})$ 回归，旗面顺向斜率 $\le 0.02$（微逆风漂移）；
4. 旗面不破旗杆中点：$\min(\text{body}) > c_1 \times (1 + 0.5 \times \text{pole})$；
5. 量能萎缩：$\bar v_{body} / \bar v_{pole} \le 0.9$（无量能数据时该规则 0 权重跳过）。

| 规则 | 权重 |
|---|---|
| 旗杆急促 | 3 |
| 旗面窄幅 | 3 |
| 旗面逆风小幅漂移 | 2 |
| 旗面不破旗杆中点 | 2 |
| 旗面量能萎缩 | 1 |

### 7. pennant_up 三角旗形（多）/ 8. pennant_down 三角旗形（空）

**算法步骤：**
1. 旗杆同旗形：$k = \lfloor 0.4N \rfloor$，pole $\ge 12\%$；
2. 旗面更窄：总振幅 $\le 6.5\%$；
3. 收敛（std 口径，抗噪）：前半 $\sigma_1 = \text{std}(\text{body}_{1..m/2})$，后半 $\sigma_2$，要求 $\sigma_2 \le 0.85 \sigma_1$；
4. 守住杆身：s=+1 时 $\min(\text{body}) > c_1(1 + 0.6\,\text{pole})$；s=−1 时 $\max(\text{body}) < c_1(1 + 0.6\,\text{pole})$。

| 规则 | 权重 |
|---|---|
| 旗杆急促 | 3 |
| 旗面窄幅 | 3 |
| 旗面收敛 | 3 |
| 旗面守住杆身 | 2 |

## 二、底部反转类（10 类，s=+1；顶部类 s=−1 镜像复用同一算法）

### 9. bottom_reversal 底部反转（看多）/ 15. top_reversal 顶部反转（看空）

**算法步骤：**
1. 前半段逆向下行：$k = \lfloor N/2 \rfloor$，drop $= 1 - c_k/c_1 \ge 15\%$（顶部镜像：$c_k/c_1 - 1 \ge 15\%$）；
2. 极值位置：$\text{lo}_i = \arg\min(s \times c)$ 落在 $[0.35N, 0.85N]$；
3. 右侧顺向抬升：$c_N / c_{\text{lo}} - 1 \ge 10\%$（顶部镜像回落）；
4. 近段不再下探：$\text{tail} = \max(3, \lfloor N/8 \rfloor)$，$\min(c_{N-tail+1..N}) \ge c_{\text{lo}} \times 0.995$；
5. 后半段动量转顺：对 $s \times z_{k+1..N}$ 回归斜率 $> 0.01$。

| 规则 | 权重 |
|---|---|
| 前半段逆向下行 | 3 |
| 极值点位置 | 2 |
| 右侧顺向抬升/回落 | 3 |
| 极值区不再下探/冲高 | 2 |
| 后半段动量转顺 | 2 |

### 10. v_bottom V形底（看多）/ 16. v_top V形顶（看空）

**算法步骤：**
1. **单一尖锐极值**：主极值（$s \times z$ 最深的谷/峰）之外，任何同级极值的深度差 $< 0.4 \times (z_{\max} - z_{\min})$，否则判为结构破坏；
2. 左腿 $= s \times (c_{\text{lo}}/c_1 - 1) \ge 10\%$，右腿 $= s \times (c_N/c_{\text{lo}} - 1) \ge 10\%$；
3. 右腿力度 $\ge$ 左腿绝对值 $\times 0.6$；
4. 转折尖锐：$w = \lfloor N/20 \rfloor$，$(\max(c_{\text{lo}-w..\text{lo}}) - \min(c_{\text{lo}..\text{lo}+w})) / c_{\text{lo}} \ge 6\%$。

| 规则 | 权重 |
|---|---|
| 单一尖锐极值 | 3 |
| 左腿急促 | 2 |
| 右腿急促 | 2 |
| 右腿力度 | 2 |
| 转折尖锐 | 1 |

### 11. round_bottom 圆弧底（看多）/ 17. round_top 圆弧顶（看空）

**算法步骤：**
1. 令 $x_i = -1 + 2(i-1)/(N-1) \in [-1,1]$，对 $s \times z$ 做二次多项式拟合 $\hat y = ax^2 + bx + c$；
2. 弧形显著：$a > 0$ 且 $R^2 \ge 0.5$；
3. 弧底居中：$\arg\min(s \times z) \in [0.3N, 0.7N]$；
4. 弧底平缓：中段 $[0.4N, 0.6N]$ 的 $\text{std}(s \times z) \le 0.5 \, \sigma_z$；
5. 右端不弱于左端：$s \times z_N \ge s \times z_1 - 0.3$；
6. 弧口张幅：$(s \times z)_{\max} - (s \times z)_{\min} \ge 1.4$。

| 规则 | 权重 |
|---|---|
| 弧形显著 | 3 |
| 弧底居中 | 2 |
| 弧底平缓 | 2 |
| 右端不弱于左端 | 2 |
| 弧口张幅 | 1 |

### 12. w_bottom W底/双底（看多）/ 18. m_top M头/双顶（看空）

**算法步骤：**
1. 同类极值点 $\ge 2$；在所有两两组合中取**相距最远**的一对 $(t_1, t_2)$，$t_1 < t_2$；
2. 间隔充分：$t_2 - t_1 \ge 0.12N$；
3. 双底价差：$|c_{t_1} - c_{t_2}| / \min(c_{t_1}, c_{t_2}) \le 3.5\%$；
4. 颈线幅度：$s{=}+1$ 时 $\text{bounce} = (\max(c_{t_1..t_2}) - \min(c_{t_1}, c_{t_2})) / \min(c_{t_1}, c_{t_2}) \ge 5\%$（$s{=}-1$ 镜像取最小）；
5. 前置趋势：$s{=}+1$ 时 $c_{t_1}/c_1 - 1 \le -10\%$（$s{=}-1$ 时 $\ge 10\%$）；
6. 右侧确认：$s{=}+1$ 时 $c_N > c_{t_2} \times 1.02$（$s{=}-1$ 时 $c_N < c_{t_2} \times 0.98$）。

| 规则 | 权重 | 门槛 |
|---|---|---|
| 极值点充足 | 2 | 规则分 ≥ 50 |
| 双极值间隔 | 2 | 总分 ≥ 60 |
| 双底/双顶价差小 | 3 | |
| 中间颈线幅度 | 3 | |
| 前置趋势 | 2 | |
| 右侧确认 | 2 | |

### 13. triple_bottom 三重底（看多）/ 19. triple_top 三重顶（看空）

**算法步骤：**
1. 同类极值 $\ge 3$；取 $s \times c$ 最深的 4 个候选，在全部三元组组合中筛选相邻间隔各 $\ge 0.10N$ 者，取间隔之和最大的一组 $(t_1, t_2, t_3)$；
2. 三底价差：$(\max - \min)/\min \le 4.5\%$；
3. 两次中间幅度各 $\ge 4\%$（底：反弹 $= (\text{段内高} - \text{极值})/\text{极值}$；顶镜像）；
4. 右侧确认：现价越过第三极值价 $2\%$（顺向）。

| 规则 | 权重 |
|---|---|
| 极值点充足 | 2 |
| 三底/三顶价差小 | 3 |
| 间隔均匀 | 2 |
| 两次中间幅度 | 3 |
| 右侧确认 | 2 |

### 14. head_shoulder_bottom 头肩底（看多）/ 20. head_shoulder_top 头肩顶（看空）

**算法步骤：**
1. 同类极值 $\ge 3$；**头** $= \arg\min(s \times c)$ 于极值点中；
2. 左肩 = 头左侧 $\ge 0.06N$ 之外离头最近的极值，右肩 = 头右侧同理（任一侧无极值则结构不成立）；
3. 双肩对称：$|c_{ls} - c_{rs}| / \min(c_{ls}, c_{rs}) \le 5.5\%$；
4. 头部深度：$s{=}+1$ 时 $(\min(c_{ls}, c_{rs}) - c_{\text{head}})/\min(c_{ls}, c_{rs}) \ge 3.5\%$（顶镜像）；
5. 颈线 = 双肩之间区段 $c_{ls..rs}$ 的最大值（底）/最小值（顶）；确认：$c_N \ge \text{颈线} \times 0.97$（底）/ $c_N \le \text{颈线} \times 1.03$（顶）；
6. 前置趋势：起点越过左肩价 3%（或左肩位于窗口前 10%）。

| 规则 | 权重 |
|---|---|
| 极值点充足 | 2 |
| 双肩大致对称 | 2 |
| 头部深度 | 3 |
| 颈线确认 | 3 |
| 前置趋势 | 1 |

### 21. cup_handle 杯柄形（看多）

**算法步骤：**
1. 分界 $k = \lfloor 0.75N \rfloor$；杯体 $= c_{1..k}$，柄 $= c_{k+1..N}$；
2. 杯沿 rim $= \max(\text{cup})$，杯深 $= (\text{rim} - \min(\text{cup}))/\text{rim} \ge 10\%$；
3. 杯体 $z$ 化后做二次拟合（$x \in [-1,1]$）：$a > 0$ 且 $R^2 \ge 0.45$；
4. 杯底位置：$\arg\min(\text{cup}) / k \in [0.25, 0.65]$；
5. 柄幅 $= (\max(\text{handle}) - \min(\text{handle}))/\text{rim} \le 0.35 \times$ 杯深；
6. 柄不破杯底：$\min(\text{handle}) > \min(\text{cup}) \times 1.02$；
7. 现价接近杯沿：$c_N \ge \text{rim} \times 0.96$。

| 规则 | 权重 | 门槛 |
|---|---|---|
| 杯形显著 | 3 | 总分 ≥ 60 |
| 杯深足够 | 3 | |
| 杯底居中 | 2 | |
| 柄部窄幅 | 2 | |
| 柄不破杯底 | 2 | |
| 现价接近杯沿 | 2 | |

### 22. tower_bottom 塔形底（看多）/ 23. tower_top 塔形顶（看空）

**算法步骤：**
1. 三段切分：$\text{first} = c_{1..0.3N}$，$\text{mid} = c_{0.3N+1..0.7N}$，$\text{last} = c_{0.7N+1..N}$；
2. 前段急促：$s{=}+1$ 时 $1 - \min(\text{first})/c_1 \ge 8\%$（$s{=}-1$ 时 $\max(\text{first})/c_1 - 1 \ge 8\%$）；
3. 中段平底：$(\max(\text{mid}) - \min(\text{mid}))/\bar c_{mid} \le 4\%$；
4. 后段急促：$s{=}+1$ 时 $c_N/\min(\text{mid}) - 1 \ge 8\%$（$s{=}-1$ 镜像）；
5. 极值位置 $\arg\min(s \times c) \in [0.3N, 0.7N]$；
6. 平底贴近极值：平底端点与窗口极值偏差 $\le 1\%$。

| 规则 | 权重 |
|---|---|
| 前段急促 | 3 |
| 中段平底 | 3 |
| 后段急促 | 3 |
| 极值位置居中 | 2 |
| 平底贴近极值 | 1 |

### 24. island_bottom 岛形底（看多）/ 25. island_top 岛形顶（看空）

**算法步骤（缺口判定用前复权 $h/l$，容差 tol $= 1.001$）：**
1. 扫描进岛缺口：$i \in [2, N-3]$——岛形底要求 $h_i < l_{i-1}/\text{tol}$（向下跳空，岛体整体低于前一根）；岛形顶要求 $l_i > h_{i-1} \times \text{tol}$（向上跳空进岛）；
2. 锁定岛首后扫描离岛缺口：$j \in [i+2, N-2]$——岛形底要求 $l_j > h_{j-1} \times \text{tol}$（向上跳空）；岛形顶要求 $h_j < l_{j-1}/\text{tol}$；首个满足者即岛区 $[i, j-1]$；
3. 岛内根数 $j - i \ge 2$；
4. 前置趋势：岛前顺向 $\ge 4\%$（底：$1 - c_i/c_1$；顶：$c_i/c_1 - 1$）；
5. 离岛反转：岛后顺向 $\ge 3\%$；
6. 现价脱离岛区：$c_N > \max(h_{i..j-1})$（底）/ $c_N < \min(l_{i..j-1})$（顶）。

| 规则 | 权重 |
|---|---|
| 岛形结构（双向缺口） | 3 |
| 岛内根数 ≥2 | 2 |
| 前置趋势 | 2 |
| 离岛反转 | 2 |
| 脱离岛区 | 1 |

### 26. broadening_bottom 喇叭形底（看多）

**算法步骤：**
1. 高低点 $z$ 回归：$s_h > 0$（高点抬高）且 $s_t < 0$（低点降低）；
2. 波幅扩张：$(p^h_{\text{末}} - p^t_{\text{末}}) > (p^h_{\text{首}} - p^t_{\text{首}}) \times 1.3$；
3. 后半波动放大：$\sigma_{后半}(c) \ge 1.2 \, \sigma_{前半}(c)$；
4. 下跌背景：mdd $\ge 8\%$；
5. 现价转强：$c_N \ge$ 窗口最低 $\times 1.05$。

| 规则 | 权重 |
|---|---|
| 极值点充足 | 2 |
| 高点抬高 | 2 |
| 低点降低 | 2 |
| 波幅扩张 | 3 |
| 波动放大 | 2 |
| 下跌背景 | 1 |
| 现价转强 | 2 |

> **broadening_top 喇叭形顶（看空）**：同结构，条件 4/5 换为——前置上涨 gain $\ge 8\%$、现价走弱 $c_N \le$ 窗口最高 $\times 0.95$。

## 四、整理突破类（7 类）

### 27. range_consolidation 箱体震荡（中性）

**算法步骤：**
1. 箱体窄幅：$(\max c - \min c)/\bar c \le 15\%$；
2. 无方向漂移：$|\text{gain}| \le 6\%$；
3. 上下沿触碰：$c_i \ge \min c + 0.85(\max c - \min c)$ 记上沿触碰，$c_i \le \min c + 0.15(\max c - \min c)$ 记下沿触碰，各 $\ge 2$ 次；
4. 波动未发散：$\sigma_{后半}(c) \le 1.3 \, \sigma_{前半}(c)$；
5. 收盘居箱体内：pos_last $\in [0.15, 0.85]$。

| 规则 | 权重 |
|---|---|
| 箱体窄幅 | 3 |
| 无方向漂移 | 2 |
| 上下沿均有触碰 | 2 |
| 波动未发散 | 2 |
| 收盘位于箱体内 | 1 |

### 28. ascending_triangle 上升三角形（看多）/ 29. descending_triangle 下降三角形（看空）/ 30. symmetrical_triangle 对称三角形（中性）

**算法步骤：**
1. 高点价序列 $p^h = \{c_i : i \in \text{peaks}\}$，低点价序列 $p^t$ 同理；回归得 $(s_h, \cdot)$、$(s_t, \cdot)$；
2. 水平边判定：该侧极差/均值 $\le 3\%$ 或回归斜率绝对值 $\le 0.01$；
   - asc：上沿水平 **且** $s_t > 0$（下沿抬升）；
   - desc：下沿水平 **且** $s_h < 0$（上沿下降）；
   - sym：$s_h < 0$ **且** $s_t > 0$；
3. 区间收敛：$(p^h_{\text{末}} - p^t_{\text{末}}) < (p^h_{\text{首}} - p^t_{\text{首}}) \times 0.8$；
4. 趋势中性：$|\text{slope}_z| \le 0.02 \times \max(1, 60/N) \times 60/N + 0.015$。

| 规则 | 权重 |
|---|---|
| 极值点充足 | 2 |
| 上沿结构 | 3 |
| 下沿结构 | 3 |
| 区间收敛 | 2 |
| 趋势中性 | 1 |

### 31. rising_wedge 上升楔形（看空）/ 32. falling_wedge 下降楔形（看多）

**算法步骤：**
1. 高低点 $z$ 回归 $(s_h, R_h)$、$(s_t, R_t)$；
2. 上升楔形：$s_h > 0.02$ 且 $s_t > 0.02$ 且 $s_h < s_t$（双升 + 高点升得慢 = 上倾收敛）；
3. 下降楔形：$s_h < -0.02$ 且 $s_t < -0.02$ 且 $s_h > s_t$（双降 + 高点降得快 = 下倾收敛）；
4. 通道规整：$\max(R_h, R_t) \ge 0.35$；
5. 幅度适度：$|\text{gain}| \le 30\%$。

| 规则 | 权重 |
|---|---|
| 极值点充足 | 2 |
| 高低点同向 | 3 |
| 通道收敛 | 3 |
| 通道规整 | 2 |
| 幅度适度 | 1 |

### 33. breakout 平台突破（看多）

**算法步骤：**
1. 分界 $k = \lfloor 0.7N \rfloor$；平台 $= c_{1..k}$，box_hi $= \max(\text{平台})$；
2. 平台窄幅：$(\text{box\_hi} - \text{box\_lo})/\text{box\_lo} \le 12\%$；
3. 突破：$\max(c_{k+1..N}) / \text{box\_hi} - 1 \ge 3\%$；
4. 量能配合：$\bar v_{k+1..N} / \bar v_{1..k} \ge 1.3$（无量能数据时该规则不通过）；
5. 收盘站稳：$c_N > \text{box\_hi}$；
6. 平台不散：$|c_k/c_1 - 1| \le 6\%$。

| 规则 | 权重 |
|---|---|
| 前期平台窄幅 | 3 |
| 突破平台高点 | 3 |
| 量能配合 | 2 |
| 收盘站稳平台上方 | 2 |
| 突破前平台不散 | 1 |
