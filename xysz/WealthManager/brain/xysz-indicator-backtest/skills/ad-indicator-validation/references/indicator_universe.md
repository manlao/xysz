# 指标清单与方向注册

本文档列出本 skill 支持的指标、信号规则与排名方向,是扩展指标的对照表。

## 技术面指标(内置 16 个)

### 信号型指标(支持位置型/穿越型信号)

| 指标 | 主字段 | 位置型规则(买/卖) | 穿越型规则 | 排名方向 |
|---|---|---|---|---|
| MACD | DIF−DEA | DIF>DEA 持有 / DIF<DEA 空仓 | 金叉买 / 死叉卖 | +1 |
| MA20 | MA | 收盘>MA20 持有 / <空仓 | 上穿买 / 下穿卖 | 0(不参与排名) |
| KDJ | K,D | K>D 持有 / K<D 空仓 | K 上穿 D 买 / 下穿卖 | −1(J) |
| BOLL | %B | %B>0.5 持有 / <0.5 空仓 | 上穿 0.5 / 下穿 | 0 |
| ROC12 | ROC | ROC>0 持有 / <0 空仓 | 上穿 0 / 下穿 0 | +1 |
| TRIX | TRIX | TRIX>0 持有 / <0 空仓 | 上穿 TRMA / 下穿 | +1 |
| DMI | PDI,MDI | PDI>MDI 持有 / <空仓 | PDI 上穿 MDI / 下穿 | +1(ADX) |
| OBV | OBV | OBV>MA30(OBV) 持有 / <空仓 | 上穿 / 下穿 | 0 |

### 阈值型指标(触及阈值产生事件,经状态补全成持仓)

| 指标 | 买入阈值 | 卖出阈值 | 排名方向 |
|---|---|---|---|
| RSI6 | < 30 | > 70 | −1 |
| CCI | < −100 | > 100 | −1 |
| WR10 | > 80 | < 20 | −1 |
| BIAS6 | < −6% | > 6% | −1 |
| PSY | < 25 | > 75 | −1 |
| VR | < 40 | > 250 | 0 |
| MFI | < 20 | > 80 | +1 |

### 辅助指标(无买卖信号,仅参与排名)

| 指标 | 用途 | 排名方向 |
|---|---|---|
| ATR14 | 波动率(低波动优先) | −1 |

**排名方向含义**:`+1` 值越大越优先买入;`−1` 值越小越优先买入;`0` 不参与排名合成(仅用于信号模式)。

## 基本面指标(规划扩展)

基本面指标按财报公告日 PIT 前向填充到交易日,与上述技术面指标走同一套合成/撮合链路。接入后注册方向如下(仅列常用池):

| 类别 | 指标 | 方向 |
|---|---|---|
| 盈利 | 净资产收益率TTM / 资产回报率TTM / 营业利润率TTM | +1 |
| 成长 | 营业收入增速_TTM同比 / 净利润增速_TTM同比 / 扣非净利润增速_TTM同比 | +1 |
| 质量 | 经营现金流比营业收入 | +1 |
| 质量 | 应计利润占比 | −1 |
| 安全 | 资产负债比 | −1 |
| 安全 | 流动比率 / 速动比率 | +1 |
| 估值 | 市盈率TTM / 市净率 | −1 |
| 估值 | 股息率TTM / 自由现金流TTM比总市值 | +1 |
| 规模 | 流通市值对数 | −1 |
| 治理 | 股利支付率 / 流通股占比 | +1 |

## 扩展新指标

在 `signal_engine.py` 的 `REGISTRY` 中注册五要素即可接入全链路:

```python
'新指标': dict(
    calc=lambda P: _panelize(_新指标函数, P, ['close']),   # 返回 {字段: 面板}
    signal_position=lambda V, P: ...,                      # 位置型信号(可 None)
    signal_cross=lambda V, P: ...,                         # 穿越型信号(可 None)
    default_style='position',                              # 默认风格
    dir={'主字段': +1},                                    # 排名方向
)
```
