# 回测算法逻辑说明

本文档完整描述「指标验证」的算法链路与每一步的计算逻辑,是理解与维护本 skill 的核心参考。

---

## 0. 总体流程

```
数据层 data_provider            信号层 signal_engine          合成/撮合 backtest_engine
────────────────────           ────────────────────          ────────────────────────
交易日历 + 历史股票池    →     指标值面板(逐股时序算子)  →   多指标信号合成(投票/均值)
K线面板 (日期×股票)     →     原始信号矩阵 (-1/+1/0)    →   状态补全(事件→持仓状态)
前复权                  →     两种信号风格:            →   逐日撮合(卖→重算→买)
停牌/涨跌停/ST/上市退市         位置型 / 穿越型          →   收益 + 交易成本 → 净值
                                                        →   净值 CSV(对接策略业绩分析)
```

核心约定:**所有中间量统一为 DataFrame(index=日期, columns=股票代码)**,全链路不转置、不换轴。

信号语义(贯穿全流程):

| 值 | 原始信号 | 状态补全后 |
|---|---|---|
| -1 | 买入信号 | 持有中 |
| +1 | 卖出信号 | 空仓中 |
| 0 | 无信号 | (补全为最近一次信号) |

## 1. 数据层算法

### 1.1 时间轴与股票池

- **时间轴**:交易所交易日历(`get_calendar`),截取回测区间,所有面板以它为行索引。
- **股票池**:`get_hist_code_list` 取**区间内曾上市**的全部沪深 A 股(含期间退市股票),消除生存偏差——若只用当前上市名单,回测净值会系统性偏高。
- **ST 过滤**:按证券简称含 "ST" 剔除(可用参数保留);注意这是以当前简称回溯,历史曾戴帽的股票无法识别,属已知局限。

### 1.2 前复权

采用**累计后复权指标归一化**:

```
前复权价(t) = 原始价(t) × bf(t) / bf(区间最后一个交易日)
```

其中 bf 为累计后复权指标。末日锚定真实价格,序列连续,且指标只使用当日及以前的值,无前视。**不使用单次复权指标拼接**——单次指标在分红/拆分事件次日会恢复 1.0,直接相乘会在事件次日产生反向假跳变。

### 1.3 停牌处理

停牌日(有效但无成交)**价格用前收盘价填充**:

- 收益序列不跳空(停牌期间收益为 0,持仓市值不变)
- `close` 面板中不出现 0 / NaN 断点,避免收益计算除零
- 交易可行性矩阵标记为不可交易,停牌期间不产生任何买卖

### 1.4 交易可行性矩阵

| 矩阵 | 定义 | 用途 |
|---|---|---|
| `valid` | 已上市且未退市且有行情 | 信号屏蔽 |
| `tradable` | valid 且非停牌 | 可撮合 |
| `can_buy` | tradable 且昨日非涨停 | 买入约束 |
| `can_sell` | tradable 且昨日非跌停 | 卖出约束 |

**涨跌停判定**:用**不复权**收盘价日涨幅(复权价在除权日会失真),阈值按板块:

| 板块 | 涨跌停幅度 | 判定阈值(含 0.2% 容差) |
|---|---|---|
| 主板(60/00 开头) | 10% | ≥ 9.8% 涨停 / ≤ -9.8% 跌停 |
| 创业板(30/301)/科创板(688/689) | 20% | ≥ 19.8% / ≤ -19.8% |
| ST 股(主板) | 5% | ≥ 4.8% / ≤ -4.8% |

"昨日涨停 → 今日难买入"是近似处理:真实一字板需盘口数据,此处用昨日涨停近似今日无法成交。

## 2. 信号层算法

### 2.1 指标计算

技术指标基于 AmazingData 时序算子(TimeSeriesFunction / StatisticsFunction)逐股计算,结果组装为面板。指标公式为标准定义,例如:

| 指标 | 公式 |
|---|---|
| MACD | DIF = EMA(C,12) − EMA(C,26);DEA = EMA(DIF,9);柱 = 2×(DIF−DEA) |
| KDJ | RSV = (C−LLV(L,9))/(HHV(H,9)−LLV(L,9))×100;K = SMA(RSV,3,1);D = SMA(K,3,1);J = 3K−2D |
| RSI | SMA(max(ΔC,0),6,1) / SMA(\|ΔC\|,6,1) × 100 |
| BOLL | MID = MA(C,20);UP/LOW = MID ± 2σ;%B = (C−LOW)/(UP−LOW) |
| CCI | (TP − MA(TP,14)) / (0.015 × AVEDEV(TP,14)),TP=(H+L+C)/3 |
| TRIX | 三重 EMA(C,12) 的日变化率;TRMA = MA(TRIX,9) |
| VR | SMA(上涨日量,26,1) / SMA(下跌日量,26,1) × 100 |
| MFI | 100 − 100/(1 + 正资金流/负资金流),资金流 = TP×量 |
| DMI | PDI/MDI 为方向指标,ADX = MA(\|PDI−MDI\|/(PDI+MDI)×100, 6) |

内置 16 个指标(MACD/MA20/KDJ/RSI6/BOLL/CCI/WR10/ROC12/BIAS6/TRIX/VR/OBV/PSY/MFI/DMI/ATR14),注册表可扩展。

### 2.2 信号规则(两种风格)

每个指标支持两种信号风格,**全局可选**:

**位置型(position)** —— 每个交易日都输出状态,信号密集:

| 指标 | 买入(-1) | 卖出(+1) |
|---|---|---|
| MACD | DIF > DEA | DIF < DEA |
| MA20 | 收盘 > MA20 | 收盘 < MA20 |
| KDJ | K > D | K < D |
| BOLL | %B > 0.5 | %B < 0.5 |
| ROC12 | ROC > 0 | ROC < 0 |
| DMI | PDI > MDI | PDI < MDI |

**阈值型(position 子类)** —— 触及阈值产生事件信号:

| 指标 | 买入(-1) | 卖出(+1) |
|---|---|---|
| RSI6 | RSI < 30 | RSI > 70 |
| CCI | CCI < -100 | CCI > 100 |
| WR10 | WR > 80(超卖) | WR < 20(超买) |
| BIAS6 | BIAS < -6% | BIAS > 6% |
| PSY | PSY < 25 | PSY > 75 |
| VR | VR < 40 | VR > 250 |
| MFI | MFI < 20 | MFI > 80 |

**穿越型(cross)** —— 状态切换日产生事件信号,信号稀疏:

| 指标 | 买入(-1) | 卖出(+1) |
|---|---|---|
| MACD | DIF 上穿 DEA(金叉) | DIF 下穿 DEA(死叉) |
| MA20 | 收盘上穿 MA20 | 收盘下穿 MA20 |
| KDJ | K 上穿 D | K 下穿 D |
| TRIX | TRIX 上穿 TRMA | TRIX 下穿 TRMA |
| OBV | OBV 上穿其 30 日均线 | 下穿 |

穿越判定:`A 上穿 B := (A>B) 且 (A 前一日 ≤ B 前一日)`。

ATR14 为波动率指标,无买卖信号,仅作为负方向指标参与排名合成(低波动优先)。

### 2.3 状态补全(信号 → 持仓状态)

原始信号只在事件日有值。对每只股票沿时间轴前向填充:

```
state(t) = 原始信号(t)          若原始信号(t) ≠ 0
state(t) = state(t-1)           若原始信号(t) = 0(延续最近一次信号)
state(0) = +1(空仓)            期初无信号视为空仓
```

这一步把「事件驱动信号」转成「状态驱动持仓」,是撮合逻辑能保持简单的前提。向量化实现:`replace(0, nan).ffill().fillna(1)`。

## 3. 多指标合成

### 3.1 信号模式(默认):投票制

设参与合成的指标数为 n,对每个 (t, 股票):

```
buy_ratio  = 发出买入信号的指标数 / 有效指标数
sell_ratio = 发出卖出信号的指标数 / 有效指标数

综合信号 = -1  若 buy_ratio ≥ min_buy_ratio 且 buy_ratio > sell_ratio
         = +1  若 sell_ratio ≥ min_sell_ratio 且 sell_ratio > buy_ratio
         = 0   其他(维持上一状态)
```

`min_buy_ratio / min_sell_ratio` 默认 0.5(过半数)。严格大于保证买卖票数相抵时无信号。另支持 `mean` 法:信号均值 < -0.5 买入、> 0.5 卖出。

### 3.2 排名模式:截面打分选股

把指标当作截面指标,定期(日/周/月/季)重新排名:

```
① 方向统一:负方向指标 ×(-1),使所有指标同向(值越大越优)
② 截面缩尾:MAD 法,中位数 ± 3×1.4826×MAD 截断(抑制极端值)
③ 截面标准化:CSZSCORE(默认)/ CSPCTRANK / CSRANK
④ 加权求和(默认等权)
⑤ 截面排名(CSRANK 升序):1 = 最优先买入
⑥ 调仓日取排名前 top_n 只 → 持有信号;其余 → 清仓信号
⑦ 状态补全:调仓日之间持仓不变
```

方向注册:如 RSI/BIAS/WR/CCI 为负方向(超卖优先),ROC/TRIX/MFI/ADX 为正方向,OBV/VR 等量能指标方向为 0(不参与排名合成)。

## 4. 撮合算法(逐日三步)

按交易日顺序执行,日内三步顺序固定,**卖出先于买入**:

```
for t in 交易日:
    # ① 卖出:有持仓 & 当日状态为空仓 & 非停牌 & 昨日非跌停
    for code in (当前持仓 ∩ 当日空仓信号):
        if can_sell(t, code): 持仓移除

    # ② 重算持仓(卖出失败自动延续持有,次日信号仍为空仓时重试)

    # ③ 买入:无持仓 & 当日状态为持有 & 非停牌 & 昨日非涨停
    #    受持仓数约束(topn 口径 ≤ top_n;shares 口径 ≤ 总份数)
    for code in (当日持有信号 − 当前持仓)[:剩余容量]:
        if can_buy(t, code): 持仓加入
```

约束的工程含义:

- **跌停卖不出**:持仓自动延续,后续交易日卖出信号仍有效时再卖(路径依赖,必须逐日循环)
- **涨停买不进**:跳过该标的,容量留给排序后续标的
- **停牌**:双向阻断

## 5. 收益与成本

### 5.1 组合收益(T+1 对齐)

```
w(t)      = t 日收盘持仓权重(等权 = 1/持仓数;或按权重方案)
pos(t)    = w(t-1)                      ← T+1 对齐:当日建仓次日计收益
gross(t)  = Σ code pos(t, code) × ret(t, code)
```

即**当日买入不吃当日涨幅**(信号 t 日收盘生成、按收盘价撮合,t+1 起的收益归持仓),无未来函数。

### 5.2 交易成本(按成交额计)

| 项目 | 费率 | 方向 |
|---|---|---|
| 佣金 | 0.025%,最低 5 元/笔 | 双向 |
| 印花税 | 0.05% | 仅卖出 |
| 过户费 | 0.001% | 双向 |
| 滑点 | 0.05%(5 bps) | 双向 |

最低佣金按"单笔成交额 = 换手金额/当日买入(卖出)笔数"近似,低于 2 万元/笔的方案会被显性放大,这是成本模型刻意保留的警示作用。

```
cost(t) = 佣金(t) + 印花税(t) + 过户费(t) + 滑点(t)
net(t)  = gross(t) − cost(t) / 期初资金
```

同时输出**含成本净值(net_value)**与**不含成本净值(net_value_gross)**,两者之差即成本侵蚀,用于判断策略是否只是成本敏感。

### 5.3 输出

- `backtest_nav_*.csv`:date + net_value + net_value_gross,**可直接对接策略业绩分析 skill**(完整 20 余项绩效指标 + fresh-light HTML 报告)
- `backtest_holdings_*.csv`:逐日持仓(0/1 矩阵)
- 终端摘要:总收益/年化/波动/夏普/最大回撤(起止日期)/卡玛/日胜率/年化换手/累计成本/基准对比

## 6. 未来函数防护清单

| # | 风险 | 防护 |
|---|---|---|
| 1 | 当日信号吃当日涨幅 | 收益 = 昨日权重 × 当日收益(pos.shift(1)) |
| 2 | 生存偏差 | 股票池用区间内曾上市的全部代码(含退市) |
| 3 | 复权前视 | 复权指标仅用当日及以前;末日锚定 |
| 4 | 涨跌停用复权价失真 | 判定用不复权价格 |
| 5 | 停牌收益跳空 | 前收盘填充,停牌日收益为 0 |
| 6 | 期初状态未知 | 显式定义期初空仓 |
| 7 | 指标前视 | 全部指标为因果公式(EMA/MA/HHV/REF 等),无 REFX 类未来引用 |

## 7. 已知简化假设

1. 撮合价格以收盘价近似(未用次日开盘价;信号收盘生成与收盘成交之间无时滞成本)
2. 涨跌停用昨日涨跌停近似今日无法成交,未用盘口一字板判定
3. ST 判定用当前证券简称,无法回溯历史戴帽期
4. 基本面指标(财报 PIT 接入)为规划中的扩展,当前内置指标为技术面
5. 等权假设:topn 口径按持仓数等分资金,未建模零股(100 股整数倍)约束
